# Python Contact Manager

A multi-user desktop contact manager built with Python and Tkinter.

## Features
- User registration and login
- Secure password hashing
- Add, edit, delete contacts
- Search contacts
- Scrollable contact list
- User-specific contact storage

## Technologies
- Python
- Tkinter GUI
- File-based storage
- SHA256 password hashing

## How to Run

python login.py
